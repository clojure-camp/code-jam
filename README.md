# Clojure Camp Code Jam

Choose your module below:

## Conj 2026

- [Warrior](./guides/warrior.md)
  - Write a bot to fight through a 1D dungeon.
  - Themes: beginner friendly, puzzle solving, logic
  - Concepts: clojure fundamentals, idiomatic clojure, refactoring
- [Mastermind](./guides/mastermind.md)
  - Implement the game in REPL, then write a solver or GUI
  - Themes: REPL-driven development, search/logic, simulation
  - Concepts: information theory, games, code-breaking
- [Signed Distance Fields](./guides/sdfs.md)
  - Explore functions that describe shapes and combinators that compose them
  - Themes: visual, mathy, exploratory
  - Concepts: functional composition, higher-order functions, graphics
